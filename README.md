# BASE — Eleve o Padrão

Repositório oficial da landing page da **BASE**, uma marca de alta performance voltada à vida real. O projeto apresenta uma identidade visual híbrida (Premium Editorial + Detalhes Táticos), desenvolvida com React e Tailwind CSS.

## 🚀 Tecnologias Utilizadas

* [**React**](https://reactjs.org/): Biblioteca JavaScript para construção de interfaces de usuário.

* [**Vite**](https://vitejs.dev/): Ferramenta de build super rápida para projetos web modernos.

* [**Tailwind CSS**](https://tailwindcss.com/): Framework CSS utilitário para estilização ágil e responsiva.

* [**Lucide React**](https://lucide.dev/): Ícones elegantes e consistentes.

## ⚙️ Estrutura do Projeto

A landing page foi desenvolvida em formato "Single Page" (Página Única), dividida em componentes semânticos focados em conversão e experiência de usuário:

* **Hero**: Primeira dobra com proposta de valor e CTAs.

* **Problem & Method**: Apresentação do Método ELITE e quebra de objeções.

* **Digital Experience**: Mockup de integração com o aplicativo exclusivo.

* **Tactical Evolution**: Carrossel iterativo de "Antes e Depois" dos alunos.

* **Plans**: Ofertas (Operação Starter, BASE e ELITE).

* **FAQ**: Dúvidas frequentes com funcionalidade de acordeão.

## 🛠️ Como rodar o projeto localmente

1. **Clone o repositório:**

   ```
   git clone https://github.com/SEU_USUARIO/base-digital.git
   
   ```

2. **Acesse a pasta do projeto:**

   ```
   cd base-digital
   
   ```

3. **Instale as dependências:**

   ```
   npm install
   
   ```

4. **Inicie o servidor de desenvolvimento:**

   ```
   npm run dev
   
   ```

5. Abra o link gerado no terminal (geralmente `http://localhost:5173`) no seu navegador.

## 📁 Gestão de Assets (Imagens)

As imagens oficiais do projeto (como `white logo.png` e `IMG_8319.PNG`) e as fotos dos alunos devem ser armazenadas na pasta `/public` na raiz do projeto para serem referenciadas corretamente no código.
